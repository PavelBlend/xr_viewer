X-Ray Viewer (14 ноября 2026)

Программа для просмотра *.ogf 3D моделей из игры STALKER.
Поддерживаются файлы версии 4 из ТЧ, ЧН, ЗП и из билдов новее 1865.
Чтобы отображались текстуры, нужно создать виртуальный диск T,
который ссылается на папку gamedata\textures с *.dds файлами.
Для создания и удаления виртуального диска T можно использовать файлы
Disk_T_Create.bat и Disk_T_Remove.bat.


Использование:

    xr_viewer.exe <путь_к_ogf_файлу>

    Либо можно ассоциировать *.ogf файлы с программой и открывать их
    двойным щелчком мыши.

Навигация:
    - Левая кнопка мыши         - вращение вида
    - Зажатое колесо мыши       - перемещение вида
    - Прокрутка колеса мыши     - изменение масштаба вида
